### 🔄 Автообновление IAM токена

#### 1. Кэширование IAM токена
```python
def _get_iam_token(self) -> Optional[str]:
    # Проверяем валидность текущего IAM токена
    if self.iam_token:
        return self.iam_token
    # ... получение нового токена
```

#### 2. Принудительное обновление
```python
def _refresh_iam_token(self) -> bool:
    self.iam_token = None  # Сбрасываем текущий
    new_token = self._get_iam_token()
    if new_token:
        self._init_sdk()
        return True
    return False
```

#### 3. Автоматическая retry логика
```python
# При ошибке UNAUTHENTICATED автоматически обновляем токен
if 'UNAUTHENTICATED' in error_msg:
    logger.warning(f"IAM токен истёк, обновляю...")
    if self._refresh_iam_token():
        return self.start_vm()  # Повторяем попытку
```
