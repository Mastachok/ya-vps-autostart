# Changelog

## v3.0.1 - OAuth Token Management Update

### ✨ Новые возможности

#### 🔐 Полноценное управление OAuth токеном

- **Автосохранение токена**: OAuth токен теперь автоматически сохраняется при первом добавлении профиля
- **Переиспользование токена**: При добавлении новых профилей используется сохранённый токен (не нужно вводить каждый раз)
- **Интерактивное меню управления**: Новый пункт меню "12) 🔑 Управление OAuth токеном" для:
  - Проверки валидности текущего токена
  - Обновления токена
  - Просмотра полного токена
  - Удаления токена
- **Безопасное хранение**: Токен хранится в `/opt/vps-watchdog/config/oauth-token.txt` с правами доступа 600

#### 🔄 Автообновление IAM токена

- **Кэширование**: IAM токен сохраняется после получения для избежания лишних запросов
- **Автоматическое обновление**: При ошибках авторизации (UNAUTHENTICATED) система автоматически получает новый IAM токен из OAuth
- **Retry логика**: После обновления IAM токена операция повторяется автоматически
- **Детальное логирование**: Все операции с токенами логируются для отладки

### 🐛 Исправления

- Исправлена проблема с потерей OAuth токена при перезапуске контейнера
- Улучшена обработка ошибок при получении IAM токена
- Добавлена валидация OAuth токена перед сохранением

### 📚 Документация

- Добавлена секция "🔐 OAuth Авторизация" в README
- Описаны правила безопасности при работе с токенами
- Обновлена документация меню управления

### 🔧 Технические изменения

- Улучшена функция `_get_iam_token()` с кэшированием
- Добавлена функция `_refresh_iam_token()` для принудительного обновления
- Добавлена функция `manage_oauth()` в bash скрипте меню
- Обновлён `docker-compose.yml` для правильного монтирования конфига
- Улучшена обработка ошибок в `start_vm()` с автоматическим обновлением токена

### 📦 Файлы изменений

- `docker-compose.yml` - правильное монтирование config директории
